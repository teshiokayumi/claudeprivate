# 第4回 SCP-999「くすぐりオバケ」
## タイトル案:「【SCP解説 #4】財団一かわいい怪物。触れた者を幸せにするスライム――SCP-999」

- 対象:SCP-999 / 通称「くすぐりオバケ」 / オブジェクトクラス:Safe
- 想定尺:約7分
- 画像キュー:`[EP04-IMG-XX]` は本ファイル後半の挿入画像リストに対応
- **回の位置づけ:** 恐怖系が続いた後の癒し回。全編トーン明るめ、BGMもポップに。

## 脚本

### 1. アバン(0:00〜0:35)

[EP04-IMG-01]

**先生:**(真顔)優くん。今回紹介するオブジェクトに触れた者は――例外なく、**abnormalな状態**に陥る。

**優:**(怖)うわ、来た来た。今回はどんな死に方するの……。

**先生:**(真顔)その状態とは……**笑いが止まらなくなり、幸福感に包まれる。**

**優:**(驚)……え? 幸せになっちゃうの? それだけ?

**先生:**(笑顔)それだけだ。今回は財団のオアシス、SCP-999「くすぐりオバケ」を紹介しよう。

《SCP-999 ―― The Tickle Monster / くすぐりオバケ》

**優:**(元気)やった!! ホラーじゃない回だ!!

### 2. 基本データ(0:35〜1:25)

[EP04-IMG-02]

**先生:**(通常)アイテム番号、SCP-999。クラスは――ここも注目、「Safe」だ。

**優:**(納得)Safeってことは「箱にしまえば大人しい」……あ、でも先生、前に核兵器もSafeって言ってたよね。油断させといて実は、ってパターンじゃ?

**先生:**(笑顔)いい警戒心だ。だが安心していい。999の場合は文字どおりの安全枠でね。財団の報告書の中でも珍しく、**読んでいて幸せになる報告書**なんだ。

### 3. 特別収容プロトコル(1:25〜2:30)

[EP04-IMG-03]

**先生:**(通常)収容プロトコルもどこか和やかだ。999は施設内をある程度自由に動き回ることを許可されている。

**優:**(驚)収容されてるのに散歩自由なの!?

**先生:**(通常)むしろ職員と触れ合うことが推奨されている節さえある。あと、餌やりの規定がいい。999の主食は――お菓子だ。特に甘いものに目がない。

**優:**(元気)お菓子で飼えるスライム! 完全にペットじゃん!

**先生:**(笑顔)ただし与えすぎには注意、という但し書き付きだ。かわいいだろう。

### 4. 説明(2:30〜4:10)

[EP04-IMG-04]

**先生:**(通常)本体の説明をしよう。SCP-999は、オレンジ色の半透明でゼラチン状の生物。粘液の塊のような不定形で、大きな体を弾ませながら移動する。

**優:**(疑問)匂いとかヌルヌルとか、スライム系って実際そばにいたらキツそうだけど。

**先生:**(笑顔)そこが面白くてね。999の体からは**その人が一番好きな匂い**がするんだ。ある者にはチョコレートの、ある者には焼きたてのパンの匂い。

**優:**(驚)相手に合わせて匂いが変わる!? 接待上手すぎる!

[EP04-IMG-05]

**先生:**(通常)性格は極めて人懐っこい。誰かを見つけると転がるように駆け寄って、じゃれつき、くすぐり攻撃を仕掛けてくる。そして触れられた者は強烈な多幸感に包まれる。効果は触れ合いが終わった後もしばらく続く。

**優:**(納得)名前のまんま、「くすぐりオバケ」なんだね。

### 5. ログ・事件簿(4:10〜5:50)

[EP04-IMG-06]

**先生:**(通常)999のログで特筆すべきは、治療実験だ。重いうつ状態にあった被験者と999を触れ合わせたところ、症状に劇的な改善が見られた。財団は999の粘液や能力の医療応用を研究している。

**優:**(元気)怪物っていうか、セラピー要員じゃん! 財団で一番働いてるまであるよ。

**先生:**(笑顔)そして伝説のログがこれだ。財団は999を、**あの「不死身の爬虫類」SCP-682の収容室に入れてみた**。

**優:**(怖)!? あの何でも殺すやつと!? 999が溶かされちゃうよ!

[EP04-IMG-07]

**先生:**(通常)結果は驚くべきものだった。999にじゃれつかれ、くすぐられた682は――**笑ったんだ**。あらゆる生命を憎悪するはずの682が、声を上げて。

**優:**(驚)あの682を笑わせた!? とんでもない大金星じゃん!

**先生:**(真顔)効果は一時的で、682が更生したわけではない。だがこの記録は「999の癒しは、世界で最も憎しみに満ちた存在にすら届く」ことを示した。ファンの間では語り草だよ。

### 6. 余談と締め(5:50〜7:00)

[EP04-IMG-08]

**先生:**(通常)余談を一つ。実は999の「出自」については、ファンの間で有名な考察がある。ある非常に悲しい経緯を持つ別のオブジェクトと関係している――というものだ。ただ、かなり重い話なので、今日は触れない。

**優:**(疑問)気になる終わり方するじゃん……。いつか解説してくれる?

**先生:**(真顔)シリーズが進んで、君の心の準備ができたらね。

**先生:**(通常)まとめよう。SCP-999「くすぐりオバケ」。触れた者を幸福にし、うつすら癒し、682さえ笑わせたオレンジのスライム。財団という冷たい世界の中で、ひときわ温かく光る存在だ。

**優:**(元気)今回は最初から最後まで平和だった! こういう回もいいね!

**先生:**(笑顔)ちなみに、私のポケットに飴が入っているんだが……さっきから、袖のあたりに何か柔らかいものが。

**優:**(驚)来てる来てる来てる! 999くん来ちゃってるって!! ……ずるい、ぼくも触りたい!!

**演出メモ:** オチで画面下からオレンジの触手がひょっこり出て飴を持っていく → 明るいジングル → エンドカード(権利表記+参照記事クレジット)。
