# SCP個別解説シリーズ「優と先生のSCP収容記録」

1本につきSCP1体を、優(生徒役)×先生(解説役)のまんじゅう掛け合いで深掘りするシリーズです。
キャラクター設定・立ち絵仕様・表情差分は総集編パッケージ(`../01_脚本.md` 末尾/`../02_挿入画像リスト.md` 冒頭)と共通。

## 各回の共通フォーマット(約7〜8分)

| パート | 内容 | 目安尺 |
|---|---|---|
| 1. アバン | そのSCPの一番怖い/面白い要素で掴むコールドオープン | 0:30 |
| 2. 基本データ | 番号・通称・オブジェクトクラスの提示 | 1:00 |
| 3. 特別収容プロトコル | 「どう閉じ込めているか」から性質を逆算して見せる | 1:30 |
| 4. 説明 | そのSCPが何者か。優の質問で掘り下げる | 2:00 |
| 5. ログ・事件簿 | 実験記録・探査記録・インタビューの見どころ | 2:00 |
| 6. 余談と締め | 小ネタ・考察・次回予告 | 1:00 |

- 画像キューは `[EPxx-IMG-yy]` 形式。各回ファイル後半の挿入画像リストに対応。
- 毎回のお約束:アバンで優がビビる/締めで先生が一言残して優がツッコむ。
- エンドカードには毎回、`../03_権利表記と注意事項.md` の権利表記+参照記事クレジットを表示。

## 話数運用メモ

- 恐怖系(173/087/049)と緩和系(999)を交互に挟むと視聴が続きやすい。第5回3008は「怖いけど笑える」中間色。
- 各回は独立視聴可能にする(冒頭でシリーズ前提を毎回15秒で再説明)。
- 総集編(`../01_脚本.md`)はシリーズの「第0回」または再生リストの入口として使用可能。
