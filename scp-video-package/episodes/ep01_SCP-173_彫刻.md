# 第1回 SCP-173「彫刻」
## タイトル案:「【SCP解説 #1】まばたき禁止。すべてはこの彫刻から始まった――SCP-173」

- 対象:SCP-173 / 通称「彫刻」 / オブジェクトクラス:Euclid
- 想定尺:約7〜8分
- 画像キュー:`[EP01-IMG-XX]` は本ファイル後半の挿入画像リストに対応

---

## 脚本

### 1. アバン(0:00〜0:35)

[EP01-IMG-01]

**先生:**(真顔)優くん。今から10秒間、まばたきを我慢してみてくれ。

**優:**(疑問)え? いいけど……なんで?

**先生:**(真顔)もし目の前に「彼」がいたら、それが君の寿命だからだ。

**優:**(怖)……その言い方、絶対ろくなやつじゃないでしょ!!

**先生:**(通常)今回は記念すべきシリーズ第1回。SCPのすべてが始まった一体、SCP-173「彫刻」を解説しよう。

《SCP-173 ―― The Sculpture / 彫刻》

**演出メモ:** タイトルコール後、OPジングル(5秒程度)。

### 2. 基本データ(0:35〜1:30)

[EP01-IMG-02]

**先生:**(通常)まずは基本データから。アイテム番号、SCP-173。オブジェクトクラスは「Euclid」だ。

**優:**(疑問)ユークリッドって、たしか「挙動が読めなくて収容に注意がいる」やつだよね。

**先生:**(笑顔)よく覚えてたな。173は「収容自体は難しくない。ただしルールを一つでも破れば即死者が出る」という、Euclidの見本みたいなオブジェクトなんだ。

**優:**(困)ルールを破れば即死……穏やかじゃないなぁ。

### 3. 特別収容プロトコル(1:30〜3:00)

[EP01-IMG-03]

**先生:**(通常)特別収容プロトコルを見てみよう。173は施錠されたコンテナに収容される。そして人員が中に入る場合は、**必ず3名以上**で入室すること。

**優:**(疑問)なんで3人? 2人じゃだめなの?

**先生:**(真顔)理由は単純。**誰か1人が、常に173を見続けていなければならない**からだ。173は「視線が向いている間は動けない」。逆に言えば――

**優:**(怖)目を離した瞬間に動く……!

[EP01-IMG-04]

**先生:**(通常)そこで入室者は交代でまばたきをする。全員が同時に目を閉じる瞬間を作らないためだ。

**優:**(困)まばたきのシフト管理て。地味なのに命がけすぎる……。

**先生:**(笑顔)ちなみに収容室の床には、定期的に清掃が必要な「赤茶色の物質」が溜まる。正体は――血液と排泄物の混合物だ。

**優:**(驚)彫刻なのに!? 生き物なの!? 待って、informationが怖い!

### 4. 説明(3:00〜4:40)

[EP01-IMG-05]

**先生:**(通常)では本体の説明だ。SCP-173はコンクリートと鉄筋でできた彫像で、スプレー塗料の痕跡がある。そして明確な敵意を持っていて、視線が外れた隙に高速で接近し――首を折る、あるいは絞殺する。

**優:**(怖)石像に絞められるのは嫌だなぁ……。動くとこ、誰も見たことないんだよね?

**先生:**(真顔)ああ。ただし「音」は聞こえる。誰も見ていない収容室の中から、石が床を擦る音がね。

**優:**(怖)やめてやめて、想像しちゃったじゃん!

[EP01-IMG-06]

**先生:**(通常)怖さの核心は「対処法が分かりきっているのに、絶対に安心できない」ことだ。見ていれば安全。でも人間は、まばたきを完全には我慢できない。照明が落ちたら? くしゃみが出たら?

**優:**(困)人間の生理現象がそのまま弱点になってるのか……。設定が上手すぎる。

### 5. ログ・事件簿(4:40〜6:20)

[EP01-IMG-07]

**先生:**(通常)173の記録で象徴的なのは、やはり収容違反の想定だ。停電などで照明が落ちると、収容室の扉が施錠されていても、清掃や実験のタイミングと重なれば犠牲者が出る。財団の報告書は、その犠牲を淡々と「記録」として処理していく。

**優:**(困)人が死んでるのに、書き方がずっと事務的なんだよね……。

**先生:**(真顔)その「事務的な冷たさ」こそSCPの様式美だ。そしてもう一つ。173の報告書は、**2007年に匿名掲示板へ投稿された、SCPというジャンルそのものの始祖**でもある。

[EP01-IMG-08]

**優:**(驚)そうか、この一体がバズらなかったら、SCP財団も、何千件の報告書も、この動画も存在しなかったんだ。

**先生:**(笑顔)まさに「すべての始まり」。だからファンからは敬意を込めて「初代」「顔」と呼ばれているわけだ。

### 6. 余談と締め(6:20〜7:30)

[EP01-IMG-09]

**先生:**(通常)余談を一つ。原典の報告書に添えられていた写真は、実在する彫刻作品を撮影したものでね。作者のご厚意でWiki掲載だけが許されている特別な画像なんだ。だからこの動画の173は、雰囲気を再現したオリジナルデザインにしてある。

**優:**(納得)本物の写真は使っちゃいけないんだね。創作のルールもちゃんとしてるんだ。

**先生:**(通常)さて、まとめだ。SCP-173、通称「彫刻」。見ている間は動けない、しかし目を離せば一瞬で首を折る、SCPの原点にして頂点の一体。

**優:**(元気)第1回にふさわしい王道だったね! 次回も楽しみ!

**先生:**(真顔)ところで優くん、さっきから君の後ろにいるのは誰かな。

**優:**(怖)えっ!?(振り向く)……って、誰もいないじゃん!! 先生!?

**先生:**(笑顔)いま君、私から目を離したね。実戦なら終わってたぞ。

**優:**(困)そういう教育やめてくれる!?

**演出メモ:** オチと同時に画面端に173シルエットを1フレーム挿入 → エンドカード(権利表記+参照記事クレジット)。

## 挿入画像リスト

**共通スタイル:** 総集編パッケージの共通指定(低彩度・施設ホラー・グロ控えめ)に準拠。173本体は必ずオリジナルアレンジデザイン(本家写真使用禁止/`../03_権利表記と注意事項.md` 参照)。

### EP01-IMG-01|アバン:暗闇の中の目
- **内容:** 真っ暗な画面に、大きく見開かれた人間の目のクローズアップだけが浮かぶ。目は血走り、涙がにじみ、「まばたきを我慢している」極限状態。瞳にコンクリート質感の何かのシルエットが小さく映り込んでいる。
- **演出:** 10秒カウントのテロップと併用。
- **形式:** 横長16:9

### EP01-IMG-02|基本データパネル
- **内容:** 財団風の機密ファイル画面。「ITEM #: SCP-173」「OBJECT CLASS: EUCLID」の大きな見出し、Euclidを示す黄色のクラスアイコン、下部に黒塗りだらけのダミーテキスト。
- **演出:** タイプライター風に文字が打ち出される。シリーズ全回で使い回せるテンプレとして作成(番号・クラス差し替え式)。
- **形式:** 横長16:9、テンプレート

### EP01-IMG-03|収容室と3人1組の入室
- **内容:** 白いタイル張りの収容室に、防護服の職員3名が入室する俯瞰図。部屋の隅に173(オリジナルアレンジ:コンクリート質感の人型、緑の飛沫塗装、赤黒い落書き風の顔)。職員のうち1人の視線が173に向いていることを示す視線の点線。
- **演出:** 視線の点線を強調表示して「常時視認」ルールを図解。
- **形式:** 横長16:9、俯瞰図解

### EP01-IMG-04|まばたき交代の図解
- **内容:** 3人の職員の顔アイコンが横に並び、「開/開/閉」→「開/閉/開」→「閉/開/開」と交代でまばたきするタイムライン図。下に「全員同時に目を閉じる瞬間を作らない」ことを示す禁止マーク付きのNGパターン。
- **形式:** 横長16:9、インフォグラフィック

### EP01-IMG-05|173本体の全身
- **内容:** 収容室の隅に立つ173オリジナルアレンジの全身。監視カメラ視点(画面隅にREC・日時)。床には排水溝と赤茶色の汚れ。距離違い(遠/中/至近)で3枚作成し、カット切替で「近づいてくる」演出に使う。
- **演出:** 至近距離版は顔のアップで恐怖のピークを作る。
- **形式:** 横長16:9×3枚、監視カメラ風フィルタ

### EP01-IMG-06|「見ていれば安全」の崩れる瞬間
- **内容:** 一人称視点。廊下の先に173が立っており、画面が「まばたき」のように一瞬黒くなる合成用素材。黒フレームを挟んだ次のカットでは173が数メートル手前に。
- **演出:** まばたき暗転はエフェクトで付与するため、同一構図で距離違い2枚があれば成立。
- **形式:** 横長16:9×2枚、一人称視点

### EP01-IMG-07|事務的な報告書のクローズアップ
- **内容:** 「事案報告」と題された財団書類。犠牲者数が無機質な数字で記録され、末尾に「プロトコルは正常に機能した」という趣旨のダミー一文。黒塗り多数。
- **演出:** 「淡々とした冷たさ」の解説に同期して数字部分をハイライト。
- **形式:** 横長16:9、書類クローズアップ

### EP01-IMG-08|「すべての始まり」年表カット
- **内容:** 総集編IMG-06(年表)の流用可。新規に作る場合は、173のシルエットから光の線が伸び、無数の報告書アイコンへ枝分かれしていく「始祖」イメージ。
- **形式:** 横長16:9

### EP01-IMG-09|余談:美術館風カット
- **内容:** スポットライトを浴びて台座に立つ「彫刻作品」としての173アレンジ。美術館の展示風の落ち着いた画。ホラーではなく敬意のトーンで、原典画像の逸話を語るパートに合わせる。
- **形式:** 横長16:9

**サムネイル推奨:** EP01-IMG-05(至近距離版)+「まばたき、できる?」の大テロップ+「#1」のシリーズナンバリング。
