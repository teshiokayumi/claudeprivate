# SCP解説動画 制作パッケージ

「SCP財団とは何か」を解説する約10分の動画を制作するための一式です。

## 収録内容(制作順)

| # | ファイル | 内容 |
|---|---|---|
| 1 | [01_脚本.md](01_脚本.md) | 優(生徒)×先生の掛け合い台本 全8シーン(約10分/表情差分指定・画像キュー・テロップ指定・演出メモ付き) |
| 2 | [02_挿入画像リスト.md](02_挿入画像リスト.md) | まんじゅう2体のデザイン仕様+脚本の `[IMG-01]`〜`[IMG-19]` に対応する挿入画像19点の発注書 |
| 3 | [03_権利表記と注意事項.md](03_権利表記と注意事項.md) | CC BY-SA 3.0対応・概要欄テンプレート・SCP-173本家画像の使用禁止など、公開前チェック事項 |

## 制作フロー

1. まんじゅう立ち絵2体を作成(デザイン仕様は `02_挿入画像リスト.md` 冒頭、必要な表情差分は `01_脚本.md` 末尾の一覧)
2. `01_脚本.md` でボイス/字幕を打ち込み
3. `02_挿入画像リスト.md` の優先度「高」から挿入画像を作成(すべてオリジナル作画/生成前提)
4. 編集後、`03_権利表記と注意事項.md` のテンプレートを概要欄・エンドカードに反映して公開

## 動画概要

- **タイトル案:** 【SCP解説】先生、SCPって結局なんなの?――世界最大の共同創作ホラー入門
- **キャラクター:** 優(生徒役の男の子・リアクション担当)/先生(解説役・研究員風)のまんじゅう2体
- **想定尺:** 約10分(シーン6の紹介オブジェクト数で調整可能)
- **構成:** フック → SCPとは → 起源(2007〜) → 報告書の読み方 → オブジェクトクラス → 有名SCP×5 → 世界観と人気の理由 → まとめ
